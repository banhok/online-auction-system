# online-auction-system

Online Auction System - Advanced Programming Final Project (Java, JavaFX, Socket, MVC, Maven, JUnit, GitHub Actions)



**## Overview**

**Bài tập lớn Lập trình nâng cao: Phát triển hệ thống đấu giá trực tuyến**



**## Team members**

**- Thành viên 1: GitHub manager / auth / CI / docs**

**- Thành viên 2: server / auction logic / concurrency**

**- Thành viên 3: client UI / realtime update / testing**



**## Tech stack**

**- Java**

**- JavaFX**

**- Maven**

**- JUnit**

**- GitHub Actions**



**## Branching strategy**

**- `main`: bản ổn định**

**- `develop`: nhánh tích hợp**

**- `feature/\*`: nhánh chức năng**

**- `hotfix/\*`: sửa lỗi gấp**

**- `release/\*`: chốt bản demo / nộp bài**



**## Team rules**

**- Không push trực tiếp vào `main`**

**- Mọi thay đổi phải qua Pull Request**

**- `main` yêu cầu 2 approvals**

**- `develop` yêu cầu 1 approval**

**- Commit rõ ràng, thường xuyên**
